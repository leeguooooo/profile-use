# Security policy

Security fixes target the latest released version. Upgrade before checking whether an issue still reproduces.

## Reporting a vulnerability

Email leeguoooo@gmail.com with the affected version, platform, reproduction steps and expected impact. Do not publish personal data, documents, credentials or exploit details in public issues. Use synthetic profiles for reproductions. We will assess reports and coordinate fixes and disclosure; there is no guaranteed response time or bounty program.

## Boundaries

Profile data belongs outside source control. Masked output reduces incidental disclosure but is not an authorization boundary. Raw values an agent reads can enter its model-provider context and the destination form; use a provider and destination you trust. Confirm sensitive-field use, document uploads and submission separately. Vault synchronization sends encrypted data to your configured Bitwarden or Vaultwarden server. See the README for the complete data-flow model.
